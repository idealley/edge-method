# Contributing

This repository contains no code, and it will stay that way.

Welcome, by pull request:
- Worked examples: a filled-in set of documents (01 to 07) from a real run, with names and numbers you are allowed to publish. A partial run is fine if it says where it stopped and why.
- Translations of the documents. Keep the file names; add a language suffix.
- Corrections: a step that contradicts the method page, a broken link, a sentence that does not say what it means.

Declined, with thanks: anything that turns this repository into code. Scripts that fill the documents, agents that run the method, tooling that draws the map. The method's rule is no code and no AI before the method has run; the repository follows its own rule.
