# 02 · Name the destination

**Step 2 of 7 · Phase: Awake · Output: destination, learning-loop hypothesis, CEO mandate in writing.**

The map tells you where you are. This page says where you are going and who is paying for the trip. Without it the Cut in step 4 degenerates into cost-cutting, and the edge in step 6 gets defunded the first quarter it embarrasses someone.

Fill it on one page. Blanks in brackets. Sign it.

## The exponential question

What does marginal cost of supply toward zero mean for this firm?

Not for the industry, not for a competitor with a different balance sheet. For this firm, with the workflow you mapped. Answer it concretely: which activity in the workflow stops costing anything per unit once it is done right once, and what that lets you sell, refuse, or stop charging for.

```
For [firm], marginal cost of supply toward zero means:

[Two to four sentences. What becomes free per unit. What the firm
does with that. What it stops doing.]

The part of the mapped workflow where this shows up first:
[component from the map]
```

## The learning-loop hypothesis

The exponential question only pays if something compounds. Name the loop: what the firm learns each time the workflow runs, where that learning is stored, and what gets cheaper or better on the next run because of it. If the answer is "in people's heads", there is no loop yet; step 5 will build one.

```
Each time [workflow] runs, we learn: [what]
That learning is stored in: [where, today]
It makes the next run: [faster / cheaper / more accurate, how]
It currently leaks because: [what stops it from compounding]
The loop lives at: [the component on the map where the loop should sit]
```

## The CEO mandate

Written, signed, kept. This is the document the edge points to when the division it will replace asks who authorized it. The rules it encodes come from the method, not from this template: the edge is funded by the CEO, never by the division it will replace; the old way stays live until the new way has provably won; benchmarks are set before the run and do not move.

```
MANDATE

I, [name], [title], authorize the reinvention of [workflow]
using The Edge Method.

Destination: [one sentence, from the exponential question above]

The first workflow is chosen at step 3. Whatever it is:
- It is funded from [CEO budget line], not from the division it replaces.
- The old way stays live until the new way has provably won on
  benchmarks fixed before the shadow run.
- The benchmarks are: cycle time, error rate, cost, parts deleted.
  They are written down before the run and are not renegotiated during it.
- The team that runs the workflow today joins at step 5, not before.
- If the override rate does not fall during the shadow run, I will be
  told so before any decision to scale.

Signed: [name]     Date: [date]
```

## Before you move on

- The exponential question is answered for this firm, not in general.
- The learning loop is named, located on the map, and its leak is identified.
- The mandate is signed by the person who controls the budget.

Commit the page. Step 3 picks the one thing.
